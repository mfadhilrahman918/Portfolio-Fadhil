# Portofolio Muhammad Fadhil Rahman

Website statis (HTML + CSS + JavaScript), tanpa instalasi apa pun.

## Struktur
- index.html : isi dan urutan section
- css/style.css : warna (variabel di atas file), ukuran, animasi
- js/main.js : black hole, teks mengetik, filter proyek, kursor, form
- assets/ : taruh foto.jpg di sini

## Cara menjalankan di Antigravity
1. File > Open Folder, pilih folder portfolio-fadhil.
2. Pasang ekstensi Live Server, klik kanan index.html > Open with Live Server.
   (Alternatif: klik dua kali index.html untuk membukanya di browser.)

## Yang bisa Anda ubah dengan cepat
- Warna: variabel --bg, --blue, --cream di css/style.css
- Teks headline: array w di js/main.js
- Proyek: blok <article class="card"> di index.html (atribut data-t = kategori filter)
- Tema black hole: fungsi draw() di js/main.js
